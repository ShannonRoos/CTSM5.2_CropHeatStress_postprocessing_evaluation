Postprocessing script used for evaluation of CLM crop heat stress experiments, and evaluation against ESA-CC LST and EarthStat-FAO yield data.
Published on 28-07-2026
Repository contains
  - grainc_global: functions related to postprocessing of CTSM crop data. Many functions here are taken from Rabin et al.(2021), doi: https://doi.org/10.5194/gmd-16-7253-2023
  - utils: these are functions from NCAR also related to postprocess CLM model output
  - HW_trigger_analysis: Jupyter notebook with the code for the first part of the results, in which the frequency of triggered heatwaves is assessed
  - CLM5_HS_analysis: Jupyter Notebook for the yield analysis against Earthstat-FAO yield data (second part of results)
  - Appendix_LAI_HS_TVPEAK: Jupyter Notebook for appendix analyisis related to LAI and GPP of different experiments
  - Appendix LST_TSLIN_evaluation: Jupyter Notebook to compare monthly LST (K) from ESA-CCI with CLM control skin temperature (K)
